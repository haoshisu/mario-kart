# Kestrel — 原創車輛灰模造型審查

使用者於 2026-10-07 提供三張車輛／角色渲染圖作為品質與美術方向參考。
本模型取用的視覺特徵是連續圓潤曲面、飽滿車體、寬輪距、明確座艙與可讀機械細節。
圖片中的角色、徽章、車體零件與像素未被匯入模型。

## 本輪交付

- `kestrel-clay.blend`：可編輯的原創曲面模型，保留 subdivision、Bezier 曲線與座椅厚度 modifier。
- `geometry.json`：評估後的幾何統計與非有限座標檢查結果。
- `../../doc/images/kestrel-study/`：前側、俯視、後側及側面四個實際 Blender 渲染。
- 生成來源為 `../../scripts/build-kart-shape-study.py`。

以白灰色材質檢視表面與輪廓；不含車手、正式車漆、布料、發光特效與動畫。
這是造型審查用高精度模型，尚未產生符合遊戲預算的 LOD、烘焙貼圖或正式 GLB。
使用者已於 2026-10-07 核准本灰模。正式版本由 `../../scripts/build-kestrel-models.py` 產生，遊戲使用 Kestrel；此資料夾保留原始造型審查版本。

## 造型決定

1. 扁平圓角車頭與下沉前緣，避免單純平面楔形或鼓起的半球。
2. 寬弧形前翼、分離側進氣罩與開放座艙，形成不同方向都可辨識的輪廓。
3. 中置單排氣、後方散熱蓋、分流器與雙側懸吊，保留自己的車尾設計。
4. 圓肩輪胎、凹入輪圈、分叉輪輻、螺帽與環向胎溝，細節由幾何呈現。
5. 輪軸位置沿用既有遊戲配置作尺寸參照；灰模未取得遊戲整合驗收。

## 重建

在 Blender 4.5.11 LTS 執行：

```bash
blender --background --threads 4 --python scripts/build-kart-shape-study.py
```

從專案根目錄執行。腳本會重建本資料夾與灰模四視圖，保留遊戲中的 v1／v2 資產。

## 已核准造型

先確認車鼻的寬度與弧度、輪胎相對車體的大小、座艙位置、前翼輪廓與車尾造型。
正式材質、原創車手與幾何優化由正式模型腳本處理；遊戲整合規範與驗證見 `../../tech-doc/art-direction.md`。

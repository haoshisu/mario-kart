# 豆豆 Dodo — 原創卡通賽車手造型稿

2026-10-15：依使用者要求，用 Blender 製作活潑、誇張比例的卡通車手。大頭短身、翹髮、琥珀護目鏡、青綠賽車服與橘色護肩，雙折線隊徽為原創。無外部角色、模型或貼圖。

- `dodo-racer-v1.blend`：可編輯的分件模型與攝影棚、燈光及主視角相機。
- `dodo-racer-v1.glb`：僅角色的 Y-up GLB；前方 -Z，公尺單位。
- `dodo-hero.png`、`dodo-front.png`、`dodo-back.png`：Blender Cycles 實際模型渲染。
- 生成來源：`scripts/build-dodo-racer.py`；Blender 4.5 LTS 背景執行。

這是獨立美術研究稿，未取代遊戲 Aster 或變更既有美術方向。約 39,236 三角形，GLB 約 853 KiB；未減面、未綁骨架、未製作坐姿／動畫，未達既有「車身＋角色 12,000 三角形」預算，不可直接當作已驗收的正式遊戲角色。後續整合需調整座姿、材質批次及幾何預算並驗證遊戲畫面。

# 本機練習紀錄（2026-10-22）

依「開始下一階段」進入重玩目標，這輪先實作練習模式的各賽道個人紀錄。

- 完成合法三圈後保存最佳總時間與最快單圈，兩項可來自不同次完賽；未完成的單圈不入庫。
- 駕駛 HUD 顯示挑戰目標；結算顯示首次完成、刷新總時間／單圈、追平，或比原最佳快／慢幾秒。比較精度為百分之一秒。
- 每個賽道、圈數與駕駛規則版本獨立儲存。使用瀏覽器 localStorage，重新整理後保留；清除瀏覽器資料會刪除紀錄，不會同步其他裝置。
- 格式損壞視為沒有紀錄；讀寫受阻會顯示無法保留訊息，仍可完成及重新比賽。
- 純規則在 core/race/practiceRecords.ts，儲存與單次完賽去重在 runtime/practiceRecordStore.ts，React 透過外部快照訂閱；每幀不讀寫儲存。
- 僅本機練習適用。多人／CPU 道具賽、全球排行榜、幽靈車與盃賽不在本輪範圍；網路協定維持 23。

## 驗證

新增純規則及儲存測試，涵蓋時間有效性、較慢成績不覆蓋、單圈獨立更新、版本／賽道隔離、重複完賽、重開及儲存錯誤。瀏覽器測試使用現有診斷檢查點軌跡測試結算、保存、重新整理、破紀錄提示、窄螢幕與寫入失敗；不以診斷軌跡時間作為賽道平衡或真人駕駛證據。

驗證結果：`npm run check` 通過（70 檔／616 項）；其後補入換圖殘留快照防護，相關兩檔 23 項測試及 lint／typecheck 再次通過。最終 production build 通過，Brave 三項瀏覽器情境通過（約 1.2 分鐘）。既有 Rapier 初始化參數棄用提示仍由依賴套件輸出，沒有新增瀏覽器執行錯誤。已檢視 [桌面結算](../doc/images/practice-records/desktop-finish.png) 與 [窄螢幕結算](../doc/images/practice-records/mobile-finish.png)；截圖時間為診斷測試資料。尚未部署，未做手機真機驗收。

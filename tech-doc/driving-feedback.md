# 駕駛提示與事件優先序

2026-10-22：依使用者下一階段要求，補強正式對戰（參賽房主、鍵盤單人對戰與手機）的操作回饋。練習已有的漂移儀表保留。

- 漂移中呈現三級色格、等級與放開加速提示；零級提醒同向轉彎充能。數字及文字與顏色並用。
- 受擊以權威事件顯示飛盤／光球／陷阱及攻擊者，不再一律用陷阱圖示；缺事件時只顯示已知的受擊狀態，不猜來源。
- 受擊優先於抵擋、漂移、一般道具、Turbo、其他加速及持續保護。抵擋不會被同 tick 後續拾取蓋掉。
- 一般事件提示有效 1.25 秒，依既有 60 Hz 權威 tick 判定，排除未來事件及其他玩家事件。沒有新增計時器或網路狀態。
- 秒數與文字分開，秒數對讀屏隱藏；提示鍵不隨倒數變化，不重新觸發入場動畫。沿用減少動態偏好，長來源名稱可換行且限制橫幅寬度。
- 完賽或 DNF 不再顯示駕駛橫幅與螢幕道具效果，保留上一輪完賽等待提示。

本輪不改漂移充能、速度、道具機率、傷害或輸入規則，協定維持 23。尚未部署。

# 台灣城市系列：3D 街景

2026-10-17 使用者要求地圖場景 3D 化，先做台灣城市系列。既有專案已有台北、九份、高雄、阿里山的 3D 路線與基礎建築；本次在前三張城市／山城地圖補齊沿路可見的立體街景，不新增同名賽道。

- 台北・霓虹疊城：騎樓後方的玻璃店面、豆花／茶行／小食招牌、條紋雨棚、夜市直立燈箱、陽台欄杆、冷氣、盆栽及屋頂水塔。
- 九份・金霧飛城：山城茶屋招牌、門窗木框、成串立體燈籠、茶桌茶具與椅凳。
- 高雄・轉港狂潮：海風倉庫招牌、港邊商行與海風冰室、遮棚、櫃台及高腳凳。

沿用既有城市地標、遠景、地形、道路高低與捷徑。阿里山、其他七圖、賽車物理、關卡進度、障礙與多人協定不變；網路版本維持 21。

## 資產與整合

新模型由 `scripts/build-taiwan-city.py` 在 Blender 4.5 建構；可編輯原檔、逐網格面數及重建說明位於 `art-source/taiwan-city/`。中文字以系統 STHeiti Light 字型輪廓轉成立體網格，沒有打包或在瀏覽器載入字型檔。店名為虛構，沒有使用外部品牌、下載模型或貼圖。

`src/game/track/taiwanCity.ts` 從既有建築位置產生配件配置，排除跨路倉庫、城門與堆疊地標。`TaiwanCityDetails` 負責依模組／材質實例化；每組兩個共享頂點色材質。標準工作距離 78 m、省電 28 m，全圖檢視省略小配件，不新增即時光源或陰影 pass。基礎建築的遠景 LOD 沿用原設定。

| 資產 | 三角形（各模組一份總和） | GLB bytes | 材質 |
| --- | ---: | ---: | ---: |
| 標準 | 14,228 | 1,005,936 | 2 |
| 省電 | 3,952 | 329,644 | 2 |

省電版改用平面字形並減少圓形分段，省略陽台欄杆、冷氣、盆栽與小家具；店面、招牌、屋頂水塔、燈籠和港邊攤位仍保留。上述是資產面數，實際場景有多個實例，不能直接當成整場渲染預算。

新配件不擴張原建築的水平安全包絡：街屋／茶樓半徑小於 6.5 m、港倉小於 11.5 m；既有建築配置已避開主路及支路。未新增視覺裝飾碰撞體。

## 驗證與圖像

新增 GLB 解析、有限座標／法線、兩材質、容量／面數及逐頂點水平包絡測試；配置測試確認穿行入口、堆疊地標和森林不套用街景配件。

實際瀏覽器測試涵蓋三圖的標準／省電模型載入、WebGL 錯誤、鍵盤加速、手機橫向版面，截圖位於 `doc/images/taiwan-city/`。`blender-streets.png` 為實際模型攝影棚渲染；`*-standard.png`、`*-drive.png`、`*-mobile-low.png` 才是遊戲畫面。

本輪 `npm run check -- -- --maxWorkers=2` 通過 lint、TypeScript、61 個測試檔／517 項測試；正式 `npm run build` 通過。最終 Brave production 共 4 項通過：三圖雙畫質與駕駛、四車同場及手機省電預算。已檢視實際遊戲與手機尺寸截圖。

初次完整測試被隔離環境的 localhost 監聽限制阻擋；允許本機伺服器後重跑全數通過。四車省電起點場景最初為 203,663 三角形，將小配件工作距離從 42 m 調至 28 m 後為 192,871 三角形／211 calls，通過原本 200,000 面數門檻。相同位置標準版為 701,418 三角形／314 calls。這是單一場景診斷樣本，標準含陰影且仍高於低畫質預算，不宣稱全賽道最壞情況均達標。部分切換畫質時診斷會取到環境貼圖 pass（2 calls／4 triangles），不採作場景效能證據。

尚未部署，未新增手機真機或長時間多人效能驗收。

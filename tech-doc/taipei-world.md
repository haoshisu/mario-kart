# 台北背景世界

2026-10-17 使用者核准先把台北背景世界補完整，再依此風格延伸其他城市。本輪只修改台北視覺環境與台北檢視視角，未變更道路、碰撞、捷徑、道具、車輛或網路協定（維持 21）。

## 完成內容

- 以原有霓虹疊城賽道為核心，外圍生成 141 棟住宅與階梯式高樓；省電版保留 71 棟。建築有外牆窗格、屋頂壓頂與部分退縮塔樓。
- 街區地坪及非賽道的背景道路連接城市街廓，空地形成留白庭院；保留沿路既有騎樓店面。
- 西側加入蜿蜒河道、雙側堤岸及兩座纜索跨河橋，含橋墩與下接地面的引道。
- 三層連續環狀山稜包圍盆地，以遠近色階呈現山景深度，搭配既有台北暮色天空。
- 「檢查賽道」進入台北城市俯瞰視角，可繼續旋轉、平移與縮放；台北遠裁切距離延伸至 2400 m。

這是以台北盆地意象創作的虛構背景，並非真實地圖重建；河岸橋梁與背景街道屬裝飾，不能駛離賽道進入。九份、高雄與阿里山保持原版本，沒有在此輪自動擴充。

## 架構與資產

`track/taipeiWorld.ts` 集中定義配置與參數，根據既有主路、各支路、建築包絡與河岸排除背景建物，包含高架道路的水平範圍。橋梁位於賽道南北邊界之外。`rendering/taipeiWorldGeometry.ts` 建構合併網格，`components/TaipeiWorld.tsx` 負責畫質與資源生命週期。

背景全部使用原創程序幾何與本機生成窗格貼圖，沒有下載模型或圖像；本輪沒有新增 Blender 模型。既有近景 Blender 城市模組繼續使用。合併後世界本體標準 7,360 三角形、省電 5,144 三角形（不含另畫的 2 三角形外圍地面），分為街區、建築、山稜、河面、兩側堤岸及橋梁。背景不增加即時陰影 pass 或光源；山景與背景使用獨立色階，避免既有駕駛霧距將整個背景抹除。卸載時釋放自有幾何、窗格貼圖及河水紋理副本，不釋放共享紋理。

## 驗證

完整 `npm run check -- -- --maxWorkers=2`：62 個測試檔、521 項測試通過，含 lint 與 TypeScript。街區地坪與相機最後調整後，再執行 lint、TypeScript、4 項背景測試及正式 build，均通過。

新增測試涵蓋建物避開主路／支路／河岸、背景橋遠離賽道、確定性配置、有限幾何及標準／省電面數預算。Brave 檢查實際全景、四車同場、手機橫向省電、鍵盤駕駛及檢查賽道視角。遊戲截圖存於 `doc/images/taipei-world/`，不是概念圖。

最終 Brave production 2 項情境全部通過，已檢視全景、檢查賽道俯瞰與實際駕駛畫面。四車省電起點樣本為 197,273 三角形／218 calls，約 60 FPS、p95 17.9 ms，通過既有 200,000 面數門檻。這是本機單一場景樣本，不代表真機或整圈最壞情況；切換場景時診斷偶爾取到環境貼圖 pass 的 2 calls／4 triangles，不採作效能證據。

尚未部署；未新增手機真機、長時間多人或整圈最壞情況效能驗收。

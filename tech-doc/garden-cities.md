# 台南與台中城市地圖

2026-10-17 使用者要求繼續製作其他城市，新增「台南・府城暖巷」與「台中・綠園光廊」，保留既有十一圖，合計十三圖。

兩圖皆為原創虛構道路，不是實際城市道路重建。台南採紅磚低樓、城樓、運河與燈籠街屋；台中採綠園道、曲面展館、現代高樓與三層丘陵。使用既有原創 Blender 騎樓／茶樓與店面 GLB，搭配合併幾何背景；沒有新增第三方資產或套件。

- 每圖六區、獨立閉合主路、一條同檢查點區間捷徑、一座可選側線大跳與移動工作車。
- 台南高低差 12 m，台中 16 m。左右路面有石磚／落葉抓地差，主路中央保持通行。
- 選圖、練習、房主、手機與 CPU 共用 TrackId 和權威路線。新增地圖使協定升至 22，前後端須同步更新。
- 建築布局避開所有主路及支路；近景沿用既有距離 LOD，背景省電模式保留建築輪廓，減少樹木、窗帶與攤位。
- `cityTracks.ts` 管路線，`gardenCities.ts` 管布局，`gardenCityGeometry.ts` 管合併幾何，`GardenCityWorld.tsx` 管場景組合及資源清理。

## 街區密度補強（2026-10-18）

依空洞感回饋新增沿路連續鋪面、高架邊緣承托、植栽花台、路燈、長椅與攤位；所有沿路物件檢查主路及支路淨空。背景樓房增加院落與低樓附屋，省電模式也保留全部樓房輪廓。建築窗帶、院落及人行道採平面幾何減少不可見面，沿用單一合併背景 mesh；省電近景細節距離由 60 m 改為 48 m，遠景輪廓持續保留。

這輪背景幾何預算為標準 42,000、省電 24,000 三角面；四車整體省電上限仍維持 200,000。沒有修改路線、權威物理或網路協定。

本輪瀏覽器首輪驗證兩圖選圖、四車省電、鍵盤駕駛與俯瞰通過；抽樣台南 186,731 面、台中 197,430 面，維持 200,000 面整體上限。已檢視街景及俯瞰截圖，並修正植栽與花台的中心對齊。

最終驗證：完整 `npm run check` 通過 64 檔／570 項，正式建置通過；植栽修正後的幾何測試與兩圖 Brave production 情境再驗通過。仍未部署，效能數據為本機指定視角抽樣。

後續更新（2026-10-18）：本頁以上保留歷史驗證。最新建築輪廓、省電策略及地形調整請見 [台灣世界層次優化](taiwan-worlds-refinement.md)。

## 駕駛節奏與選線（2026-10-21）

依使用者「開始下一階段」要求，先改善兩張城市地圖的玩法辨識度。原本兩圖特殊路面皆位於 78–83%，且同為 0.65 抓地倍率；本輪改為：

| 地圖 | 主路區間 | 挑戰與選擇 |
| --- | --- | --- |
| 台南 | 10.5–15.5%，紅磚老街 | 左側石磚阻力 0.8/s、抓地倍率 0.85；可走右側平順道路保速，或留加速增益穿越石磚。 |
| 台中 | 72–77.5%，綠丘雙彎 | 左側落葉抓地倍率 0.3、轉向倍率 0.82，沒有額外前進阻力；需提早修正側滑，右側仍是正常抓地。 |

兩條既有捷徑的中段 30–70% 使用各自路面效果，出入口保留正常操控。捷徑本身較短，取捨為台南的速度損失與台中的窄路控線。空中、路外及主路乾淨側均不套用效果；沒有額外隱形碰撞或隨機失控。每種效果由共享核心執行，練習、真人與 CPU 相同。

新紋理分別為錯縫石磚與散落葉片，沿既有道路高度／傾斜鋪設。主路與分流口前保留提前告示，捷徑告示改用路線名稱與中文操控提示；選圖說明同步介紹策略。沒有新增 mesh、模型、依賴或服務。既有道路、跳台、移動障礙及其他十一圖玩法不變。

協定由 22 升至 23，避免不同路面版本進入同一賽事；需前後端同步部署並重新整理。實際捷徑收益及真人對戰平衡仍需試玩，本輪不宣稱已完成全遊戲平衡。

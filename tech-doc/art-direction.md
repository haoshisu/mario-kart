# Phase 6 原創美術規範

車輛與環境方向（2026-10-07 使用者核准）：寫實街機，真實比例、材質與光影，保留鮮明色彩與清楚速度感；保留 Kart Lab 名稱，不使用 Nintendo 角色、標誌、造型、賽道、音樂或素材。所有本階段模型由專案 Blender 腳本建模，無外部素材。

2026-10-15 核准車手改為 Q 版：豆豆、露米、栗栗、嗶波，大頭短身、簡化五官與獨立服裝色。遊戲角色選擇與車身顏色分開；Kestrel 車體和環境方向沿用。現役模型為 `chibi-{dodo,lumi,lili,bibo}[-low]-v1.glb`，細節與驗證見 [Q 版車手整合](chibi-crew.md)。

## 首批資產

- 目前車輛「Kestrel」：核准的連續曲面車鼻、弧形前翼、側進氣罩、開放座艙、中置排氣與分叉輪輻／青色發光環；烤漆、金屬、橡膠分開材質，保留四種玩家配色與性能。
- 歷史駕駛「Aster」（已由 Q 版四車手取代）：原創人形車手，開放式頭盔、可見表情、短紫髮、布料賽車服、手套與靴子；坐姿與勝利雙手動畫。歷史 Pip 狐狸車手及 Pulse 車型保留來源，遊戲使用 Kestrel。
- 場景「Meadow Circuit」：保留既有環形路線、紅白路緣及護欄，採草原嘉年華主題，補入圓潤果樹、分層遠山、雲朵、熱氣球、中央風車、花圃、彩旗、拱門與彎道方向指示。地景不侵入駕駛區。
- Blender 原始場景與生成腳本保留；正式輸出集中 `public/models/`，Aster 歷史版本檔名 `kestrel-kart-v2.glb`、`kestrel-kart-low-v2.glb`、`kestrel-wheel-v1.glb`（Kestrel v1 與 Pulse 歷史版本保留）。

## 幾何與資源預算

| 項目 | 上限 |
| --- | --- |
| 車身＋角色 | 12,000 三角形、12 材質、1 MB GLB |
| 單輪 | 1,000 三角形、3 材質、128 KB GLB |
| 四車完整場景 | 200,000 三角形、250 draw calls（含陰影須另記錄） |
| 貼圖 | 優先純色材質；如需要，單張不超過 1024²、總下載 4 MB |

採烤漆、金屬、布料與深色橡膠，開放式頭盔讓車手表情可見。道路與建物使用共享 256² 程序紋理，無額外貼圖下載；本地光卡產生單次 128² 環境反射。正式 GLB 採 Draco，解碼器重用既有 Three.js 套件內的分發版本，不增加 npm 相依。模型縮小但 decoder 有額外首次下載／解碼成本；保留未壓縮參照檔供預算驗證，初載效能須另外實測。

## 物理與動畫對齊

Three.js 採 Y-up、車頭 -Z、1 單位 = 1 公尺。車輪半徑 0.29、中心高度 -0.14、左右 ±0.72、前 Z=-0.55／後 Z=0.62，以 `kartConfig.ts` 為準。模型不反向驅動物理，不改 Collider、Checkpoint、圈數或速度。

車身傾斜／受擊由既有權威狀態驅動；車輪滾動採速度乘 delta，前輪依 steer 轉向；勝利動作由完賽狀態驅動。重賽重置動畫，較大 frame gap 限制 delta。共用幾何、按車複製改色材質，卸載時只釋放自有材質，不誤釋放共享快取。

## 驗收

正面、側面、車尾跟車及四車俯視檢查外觀／辨識；實際撞牆、互撞、漂移、道具受擊、重生、三圈及重賽回歸。預算是開發限制，不表示已量測達標；實測與缺口記錄在 roadmap。

## 2026-10-02 視覺改版

依使用者要求，向鮮明、圓潤、誇張比例的卡通派對賽車靠近，保留原創 IP。更新既有 Blender 腳本與 GLB；場景新增 `FestivalScenery`，花朵、雲、遠山、氣球及旗幟使用共享幾何 instancing。路線、物理尺寸、碰撞、圈數與道具規則未變；立體高低差及重新設計路線不屬本輪成果。

驗證：`npm run check`（132 tests）、`npm run build`、實際 Brave 的模型載入／加速／漂移／檢視模式測試通過。GLB 預算測試通過；手機真機與四車完整場景效能仍需另驗。

本機 Brave 單車跟車視角（1440×900、標準畫質）觀測約 60 FPS、p95 17.5 ms、136 draw calls、66,796 三角形；此數字不是四車或真實手機驗收結果。

## 風車花谷路線與場景（2026-10-02）

使用者進一步核准重做賽道可玩性，取代上一輪保留橢圓的限制。新賽道以「起跑嘉年華 → 湖畔果園 → 風車連續彎 → 村落回程」組織場景。紅白路緣、奶油色路面邊線與藍綠護欄保持駕駛區清晰；彎道方向牌根據實際路線曲率放置，花圃與樹木按中心線安全距離配置。新增湖面、三棟原創村屋與以 delta time 旋轉的風車葉片。使用既有 Three／R3F，無新增套件。

參考重點是可辨識的場景主題，以及讓路段有操作／選線目的，而非複製角色、賽道或建築： [Nintendo 開發訪談](https://www.nintendo.com/en-gb/News/2025/May/Ask-the-Developer-Vol-18-Mario-Kart-World-Chapter-2-2832717.html)。立體路線與主機級材質細節仍是未達成的品質目標。

最終本機抽樣：Brave、1440×900、四車標準畫質，約 60 FPS、p95 16.9 ms、249 draw calls（含陰影）、170,252 三角形。此為指定視角的抽樣，不是整場最壞情況；道具／護盾／粒子會改變繪製量。桌面與模擬手機直橫向未見 page error，小地圖與觸控可同時顯示。真機與完整賽事峰值仍待驗收。

## 2026-10-07 寫實街機改版

使用者明確選定真實比例、材質與光影，取代歷史卡通造型方向。`scripts/build-racing-models.py` 輸出原創 R2 車身、Aster 車手與輪胎；`scripts/render-racing-preview.py` 渲染實際 Blender 資產供檢視。遊戲中使用相同 GLB，輪胎轉向、滾動與完賽歡呼沿用權威狀態。

台灣場景補入磚牆、玻璃、窗框、陽台、捲門、碼頭基座、山區地基、紅燈籠、分層樹冠與木質樹幹。道路使用細粒瀝青與混凝土護欄，水面增加凹凸反光；碰撞、CP、路線與主題障礙沿用核准玩法。光照降低環境平光，增加方向光與環境反射，低畫質仍可呈現共享 PBR 材質。

本輪驗證：`npm run check` 通過 49 檔／411 項，正式建置通過；最終幾何修正另通過 4 項 GLB 預算檢查與 lint／typecheck。Brave 通過台灣四圖標準／低畫質、加速、新模型載入、四車四配色、模擬手機橫向、高雄大跳／空中旋轉／落地加速。已檢視實際遊戲截圖與 Blender 模型預覽。

最終資產：車身＋車手 7,720 三角形／8 材質／80,976 bytes；單輪 672 三角形／2 材質／6,052 bytes。桌面四車標準畫質（1440×900）抽樣 60 FPS、p95 18.1 ms、347 calls、313,820 triangles（含陰影）；模擬手機橫向低畫質（844×390、關陰影）60 FPS、p95 16.9 ms、213 calls、197,208 triangles。兩者視角與畫質不同，不能直接當作陰影成本相減；後者在既定非陰影場景預算內。非所有路段最壞情況測量，真機與長時間效能未驗收。

場景仍是輕量程序式幾何，立面、岩層、植被密度與遠景細節仍有提升空間；此輪不宣稱照片級美術。所有改版保留原創與既有物理／玩法，未部署。

## 2026-10-07 核准 Kestrel 灰模後的正式版

使用者確認車體灰模可採用，核准正式車漆、原創車手、發光輪圈與遊戲整合。參考圖片用於品質與比例，不匯入角色／徽章／車體零件。原創灰模保留於 `art-source/kestrel-study/`；正式 Blender 與未壓縮 GLB 保留於 `art-source/`，Draco 版本於 `public/models/`。重建：`scripts/build-kestrel-models.py`；實際模型預覽：`scripts/render-kestrel-preview.py`。

沿用標準／省電畫質設定，分別載入標準／低密度車身 GLB；兩版本有相同輪軸、玩家色材質、車手動作與勝利動畫契約。輪圈使用不透明 emissive 材質，沒有新增全畫面 bloom 或遠端素材。省電版在縮減幾何時保留原曲面法線，避免因平面反射讓造型失真。切換畫質會重建材質與動畫 mixer，完賽狀態能重啟該版本的歡呼。

正式資產：標準車身＋車手 11,040 三角形／12 材質／79,556 bytes；省電車身＋車手 6,346 三角形／12 材質／59,292 bytes；單輪 1,000 三角形／3 材質／8,140 bytes。兩版歡呼實際抬高手臂，停止動畫會恢復握方向盤姿勢，GLB 回歸檢查涵蓋此條件。

2026-10-08 驗證：`npm run check` 通過 49 檔／414 項，production build 通過；最後動畫調整再通過 lint、typecheck 與 7 項 GLB 檢查。Brave production 已通過台灣四圖標準／省電載入與加速、四車配色、模擬手機橫向、漂移、高雄大跳／旋轉／落地加速、三圈結算與重賽、檢查點重生。E2E 模擬穿越檢查點工具改為使用該檢查點高度，正式遊戲的高度限制與圈數規則未修改。

本機四車標準畫質（1440×900）抽樣 60 FPS、p95 16.8 ms、406 calls、348,964 triangles（含陰影）；省電橫向視窗（844×390）60 FPS、p95 16.9 ms、241 calls、195,940 triangles，在非陰影場景預算內。桌面標準畫質仍高於 200,000／250 的非陰影參考預算；數字來自指定視角，未涵蓋所有路段、真機或長時間效能。手機房間面板仍會遮擋部分車輛，這次沒有重做房間 UI。

正式車輛展示圖為 `doc/images/kestrel-finished.png`，實際遊戲畫面為 `doc/images/kestrel-in-game.png` 與 `doc/images/kestrel-four-cars.png`。展示圖使用 Blender 攝影棚燈光，遊戲光照與跟車視角會產生不同觀感。場景細節仍沿用上一輪程序式美術，本輪完成車輛整合，未部署。

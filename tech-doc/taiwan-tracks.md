# 台灣地景原創賽道（2026-10-05）

使用者已審閱台北、九份、高雄、阿里山四圖提案並核准修改。採新增四圖、保留既有七圖，總計十一圖。所有道路、建築模型與道具均為原創程序式造型；地理只提供辨識元素，不依照真實街道、尺度或地標位置重建。

## 共通規則

每圖八區，閉合主路、三圈及三個 CP 沿用既有規則。各含高速段、窄路／連彎、28–44 m 高低差、可選側線大跳、實體移動障礙、一條同 CP 區間捷徑、主題路面與獎勵側線。中央地面線可繞過跳台；大跳為實際離地、側翻及落地 Turbo，不以移除主路製造必跳斷崖。路線時間收益仍需真人調校。

分區名稱是設計資料，場景辨識依靠造型與配色，沒有靠地名招牌建立台灣感。城市選圖卡可顯示名稱。

## 台北・霓虹疊城

- **Theme**：老城騎樓與高架都會壓縮成多層環道。
- **Visual Identity**：紅磚、連續騎樓、階梯式青綠高塔、燕尾城門、捷運車廂、密集夜市棚頂。
- **Landmarks**：北門意象跨路城門、101 意象原創塔、迪化街意象騎樓。城門形成收口，騎樓柱列限定連彎，塔基區抬升至高架層。
- **Track Layout / Gameplay Sections**：城門廣場 → 騎樓折角街 → 捷運換線平台 → 塔基長漂移彎 → 空中高速大道 → 屋頂大跳 → 夜市蛇行街 → 河岸回程。
- **Gameplay Gimmick**：30 m 高架層與下層道路交叉；夜市左線濕磚降低抓地力，內側加速條帶來風險。
- **Moving Obstacles**：側線捷運車沿軌往返，實體碰撞與旋轉使用共享時鐘。
- **Shortcut**：騎樓內街，約 13.5–24% 同 CP 區間。
- **Risk/Reward Route**：夜市濕磚內線與側線大跳，回報加速／落地 Turbo。
- **Spectacle Moment**：從高架平台離地，在下層列車通過時跨越車流；列車使用原創車廂。

## 九份・金霧飛城

- **Theme**：燈籠山城、選煉廠與礦海相連的山海迴圈。
- **Visual Identity**：紅燈籠、深綠茶樓屋頂、階地廠房、鏽色礦車、山脊、双色海水。
- **Landmarks**：九份茶樓意象、十三層選煉廠意象、陰陽海。階地承托彎道，茶樓屋簷形成窄巷通道，海岸改變操控。
- **Track Layout / Gameplay Sections**：燈籠廣場 → 茶樓窄巷 → 選煉廠階地 → 礦坑回復道 → 山脊高速彎 → 山城跨谷大跳 → 陰陽海防波堤 → 屋下回程隧道。
- **Gameplay Gimmick**：18 m 髮夾平台接 42 m 山脊，降低捷徑合流的垂直落差；回海岸後進入週期性濕滑左線。
- **Moving Obstacles**：礦車在左側作業軌道往返，可撞擊；中央安全線仍通行。
- **Shortcut**：選煉廠維修礦坑，約 27–36.5% 同 CP 區間。
- **Risk/Reward Route**：防波堤濕線加速條，八秒週期中五秒降低抓地力。
- **Spectacle Moment**：42 m 山城高台大跳後，視線由密集燈籠建築切換至礦海。

## 高雄・轉港狂潮

- **Theme**：倉庫、貨櫃與海洋建築構成港灣高速樂園。
- **Visual Identity**：紅磚倉庫、彩色貨櫃、吊掛鋼索、白色帆形轉橋、海洋弧頂、低棧道。
- **Landmarks**：駁二倉庫意象、大港橋意象、海洋建築意象。倉庫形成技術通道，轉橋為真正可行駛側線，跨港平台提供高差。
- **Track Layout / Gameplay Sections**：倉庫起跑大道 → 穿庫技術區 → 貨櫃換線場 → 跨港高橋 → 海洋基座高速彎 → 吊臂跨港大跳 → 潮汐低棧道 → 水岸衝線段。
- **Gameplay Gimmick**：28 m 港橋平台採平路傾角，避免側橋合流時兩張路面互穿；之後下到 4 m 潮汐棧道；濕線週期影響抓地。轉橋中段為 kinematic 路面與護欄，柵門有實體碰撞。
- **Moving Obstacles**：吊掛貨櫃上下移動，低位佔用側線、高位可通過；旋轉橋另具同步狀態。
- **Shortcut**：倉庫裝卸通道，約 13.5–24%。
- **Risk/Reward Route**：約 38.5–48.5% 外側轉橋比主路長但連續加速條提供回報。開放 12 秒後關門、轉動、等待、復位再開門；總週期 26 秒。為留足主路間距，橋面旋轉角誇張幅度採 15°，不是複製真橋。橋上有車時延後關閉，不能在車輛腳下轉走。
- **Spectacle Moment**：大跳越過低層活動貨輪，俯視港灣；低棧道浪花可預告濕滑時段。

## 阿里山・雲海追光

- **Theme**：森林鐵路、茶園、巨木與觀日雲海的垂直山道。
- **Visual Identity**：木造站屋、紅色森林列車、巨木、梯田、霧層、暖色日出。
- **Landmarks**：森林鐵路木站、巨木、觀日山脊。根系門洞壓縮轉向空間，列車作業軌形成動態障礙，山脊提供爬升與跳台。
- **Track Layout / Gameplay Sections**：木站平台 → 茶園梯田髮夾 → 巨木根系彎 → 森林鐵路交會 → 雲霧螺旋爬坡 → 觀日高速山脊 → 雲海跨谷大跳 → 林間下坡回站。
- **Gameplay Gimmick**：0→20→8→44 m 高差；山脊左線橫風改變轉向，風口加速條獎勵穩定操控。
- **Moving Obstacles**：原創紅色森林列車沿側軌往返，具有實體碰撞。
- **Shortcut**：巨木根系窄道，約 27–36.5%。
- **Risk/Reward Route**：山脊風口加速側線與大跳落地 Turbo。
- **Spectacle Moment**：44 m 山脊離地，從深林轉入雲海與日出。

## 實作邊界

程序式模型是可玩的第一版美術，沒有寫實建物／第三方素材。共用 TrackId、地面投影、碰撞、CP 與伺服器權威資料；多人橋面角度、門高、鎖定狀態隨 snapshot 同步，練習模式使用相同狀態機。協定升為 17，前後端需同步更新。

未新增依賴，未部署。手機真機、四人長時間效能、路線收益及美術精修仍需驗收。

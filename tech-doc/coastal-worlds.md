# 九份與高雄完整背景世界

2026-10-17 使用者要求其他城市比照台北擴充完整背景。本輪處理九份與高雄；阿里山是森林地圖，沒有納入此次城市背景擴充。保留各圖正式主路、捷徑、高低差、移動障礙與物理，網路協定維持 21。

## 九份・金霧飛城

北側山坡延伸為完整聚落，112 棟木色／磚色屋舍沿坡排列，包含斜屋頂、窗戶、陽台、地基與三條階梯巷弄。省電版保留 38 棟背景房屋。房屋的基準高度取自相同山坡網格頂點，階梯依兩側坡高插值；地基嵌入坡面支撐平坦底座。

南側增加漁村碼頭及沿海小屋，海面延伸至遠方，離岸小島與三層遠山建立海灣深度。移除原本遮住新聚落的球狀背景山丘；既有沿路茶樓、礦業階地及正式路面支撐仍保留。

## 高雄・轉港狂潮

北側港區陸地增加 64 棟高樓、立面窗帶、屋頂壓頂與街道網格，省電版保留 22 棟。西側三座碼頭含吊車、吊索與貨櫃，海上配置四艘原創貨輪，包含船首、甲板、駕駛樓與貨櫃。省電版減少吊車與窗帶數，保留港區輪廓與全部船隻。

海面延伸至城市外圍，遠方低山與既有夕色天空接續地平線。背景船隻與吊車為靜態景物，沒有增加航運模擬或碰撞機制。

## 實作與成本

`track/coastalWorld.ts` 管理城市配置與共用山坡高度；`rendering/coastalWorldGeometry.ts` 建立合併頂點色幾何；`components/CoastalWorld.tsx` 掛載各城市背景並管理卸載。這批背景為原創程序幾何，不新增外部素材、貼圖、依賴或 Blender 資產。原有沿路 Blender 模組繼續使用。

每張圖分為地形／街區、建物、港口或階梯、遠山四份合併網格，加上一個海面。背景不新增陰影 pass 或光源。海面與底板改為不重疊的可見區域：九份保留左側陸地與兩段相接的海面，高雄移除原本被海面完全覆蓋的底板，避免遠景深度閃爍；物理仍使用原路面。台北的俯瞰元件改名為 `CityOverviewCamera` 供三座城市共用，遠裁切距離均為 2400 m；其他地圖維持原設定。

## 驗證

完整 `npm run check -- -- --maxWorkers=2` 通過 63 檔／528 項測試，含 lint、TypeScript。最後畫面與 LOD 調整後再通過 lint、TypeScript、7 項背景測試與正式 `npm run build`。

背景測試涵蓋配置確定性、建築避讓主路與各支路、山坡與房屋基準高度、有限幾何／法線／顏色及兩種畫質面數預算。實際遊戲截圖位於 `doc/images/coastal-world/`，包含全景、駕駛、俯瞰與手機橫向。

Brave production 已通過九份、高雄與台北共 4 項情境；海面重疊及俯瞰方向調整後，九份與高雄最終 2 項再次通過。涵蓋標準全景、四車同場、手機橫向省電、鍵盤加速與城市檢視。`*-panorama.png` 是僅隱藏選圖面板後拍攝的真實遊戲畫面，其餘截圖保留原 UI。

四車省電起點樣本：九份 198,165 三角形／174 calls；高雄 155,364 三角形／179 calls，兩者均通過既有 200,000 面數門檻。本機約 60 FPS，p95 約 17.8–18.5 ms；這些單一位置樣本不代表整圈、真機或最壞場景。九份首輪為 209,973 三角形，透過共用 LOD 距離調整與移除被取代的舊山丘降至上述預算；未放寬測試門檻。

尚未部署，未新增手機真機與長時間多人效能驗收。

最後遠景檢視另修正大海面的深度遮蔽：外海在天空之後、城市之前繪製且不寫入深度，讓地坪與近岸水面保持正確可見。修正後九份／高雄 2 項瀏覽器情境再次全部通過，已逐張檢視最終 panorama。

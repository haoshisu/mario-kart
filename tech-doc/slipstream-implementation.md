# 尾流追逐與超車

2026-10-09。使用者以「好」核准 [互撞與追逐提案](kart-contact-feedback.md) 中的尾流玩法。多人與 CPU 賽事加入「追上前車 → 穩定跟車 → 蓄滿 → 變線超車」循環，不需要新增按鍵。

## 玩家規則

- 雙方至少 8 m/s，位於同一道路／分支、高度差不超過 1.5 m，且都在路面上正常行駛。
- 車距 3–10 m、道路相對橫向差不超過 1.2 m、車輛及道路朝向差不超過 20°，穩定跟車 0.8 秒蓄滿。換前車或離開尾流帶會重新蓄力。
- 蓄滿後有 1.2 秒變線窗口。仍須靠近原前車，車距允許 1–10 m、橫向差最多 3.5 m；為容許拉出動作，車輛朝向差放寬至 45°，道路朝向差仍限 20°。
- 有方向輸入後 0.6 秒內，後車必須朝該方向實際變線超過 0.6 m，並離開原前車的 1.2 m 尾流帶，才取得 0.7 秒加速。左右皆可，短點方向鍵可保留操作意圖；0.6 秒短窗口內，反打修正不蓋掉原方向，同向操作可刷新窗口，到期後可重新選方向。
- 橫向差使用道路投影的有號位置，縱向距離使用兩車道路的共同朝向。沿彎道行駛、前車自己轉彎或變線，不會只因車身角度／前車移動自動獲獎。失去目標後清除舊轉向意圖。
- 尾流加速度 9.5 m/s²、速度上限 19.5 m/s。與道具加速取較大效果，不累加；較強的漂移 Turbo 保留。加速結束後沿用既有平滑回落。
- 碰撞、煞車、低速、失控、重生保護、離地及離開合法路面會中斷蓄力或加速。自身行駛狀態中斷或變線窗口到期後需 0.5 秒恢復；成功加速結束後也有 0.5 秒間隔。單純失去前車／離開尾流帶可重新對準並從零蓄力。
- 權威物理射線檢查道路、護欄與主題障礙的即時位置，排除車體及 sensor；不能隔障礙、不同分支／樓層或急彎蓄力。

## 整合

純規則在 `src/game/core/kart/slipstreamSystem.ts`；伺服器 `SlipstreamSystem` 重用既有路面投影與 Rapier 世界，在解算後更新車輛資料。只有伺服器選擇前車、充能與發放獎勵。鍵盤、觸控、傾斜與 CPU 都使用原本的正常輸入，不傳位置、目標或獎勵請求。

CPU 在可追逐時對準前車車道，蓄滿後選擇道路內的側線超車。彎道限速、避障及恢復行駛仍適用，同樣會因碰撞或不符合條件中斷。

快照新增尾流蓄力、蓄滿狀態、加速剩餘時間與獎勵序號；協定升至 **19**，前後端須同步更新，既有瀏覽器頁面須重新整理。插值平滑蓄力，保留蓄滿／新獎勵的狀態切換。重賽、回大廳、重生、斷線、完賽及 DNF 清除追逐狀態。

畫面加入藍色蓄力流線、綠色蓄滿提示、超車加速火焰與提示條。風聲隨蓄力增強，蓄滿及拉出成功各有原創合成提示音，沿用手勢啟用、音量及背景靜音規則。提示條在手機直向／橫向避讓操作按鈕。

此輪未改賽道路線、角色、美術資產或道具抽選，單人練習沒有前車，維持原操控。

## 驗證

純規則覆蓋距離、車道、方向、高度、速度、分支、目標切換、時序、左右拉出、意圖失效、前車移動與彎道誤觸發。真實 Rapier 覆蓋真人跟車／變線、CPU 同規則超車、追撞中斷、重賽／斷線及會移動的實體遮擋。快照與音效另外驗證狀態切換和一次性提示。

瀏覽器測試透過實際鍵盤事件、觸控煞車與模擬傾斜事件行駛，不覆寫車輛位置或權威快照。分別確認鍵盤、手機直向、手機橫向的完整蓄力與超車獎勵、加速超過 18 m/s、提示與音效啟用，以及手機提示不擋按鈕。

正式建置與 `git diff --check` 通過。Brave production 十一種情境已通過：尾流鍵盤／手機直向／手機橫向、兩個真實玩家互撞分離、練習音效、手機音效與漂移 Turbo、漂移充能／視角切換、左右彎道貼地、直線跨接縫速度，以及護欄反彈。已檢視尾流及手機截圖，沒有頁面錯誤。

初次鍵盤追逐測試揭露過彎投影與反打覆蓋意圖問題：修正為道路相對車道、要求後車自身變線，並保留短時初始方向，新增回歸。最後鍵盤完整超車連續三次通過，反打修正後的手機兩種方向也再次通過。測試車手失去機會後會重新跟車，不一直沿用失效的變線狀態。

完整檢查的預設並行曾使九份地面三圈與工坊 CPU 三圈超時，並非玩法斷言失敗。降低為兩個 worker 後，原本的限時與斷言不變，最後反打修正後的 `npm run check -- -- --maxWorkers=2` 通過 **58 檔／479 項**，包含十一圖 CPU 三圈、碰撞、坡道、大跳、道具、快照與音效。主觀追逐節奏與數值仍需真人實玩，手機感測器真機及跨網路四人長時間驗收尚未新增；未部署。

四位均為原創，駕駛性能相同，角色選擇與車身塗裝互相獨立。

## 選擇與同步

房主可於建立房間前選角；練習模式可切換角色；手機控制器可於加入前選角。角色允許重複，車色沿用原本的配置規則。單人賽的 CPU 優先選擇尚未使用的角色，因此玩家與三位 CPU 可呈現四種造型。

共用角色目錄位於 `src/game/entities/characters.ts`。伺服器驗證角色 ID，未指定時使用豆豆，未知 ID 拒絕加入。大廳與比賽快照均包含角色，重新連線與再賽保留選擇。網路協定版本為 21，前後端需一起更新。此改動不影響物理與駕駛規則。

## Blender 與遊戲資產

`scripts/build-chibi-karts.py` 建立四款坐姿角色與原創 Kestrel 車身，輸出標準／省電版 Blender 原始檔及未壓縮 GLB 至 `art-source/chibi-karts/`，Draco 壓縮版放在 `public/models/`。早期豆豆設計稿保留作為來源紀錄；重建方式見資產資料夾的 README。

角色使用剛體手臂樞紐播放 `Victory` 歡呼動畫，依材質與動畫父節點合併網格。遊戲只替換 `PlayerPaint` 材質的顏色，保留角色服裝配色。模型使用公尺、Y 向上、前方為 -Z；輪胎沿用既有資產。

`scripts/render-chibi-karts.py` 從實際 Blender 模型產生 `public/characters/` 選角頭像及 `doc/images/chibi-crew/` 展示圖。`crew-preview.png` 為四款實際模型渲染的合圖；同資料夾的 practice、victory、four-cars 與 phone 圖片為瀏覽器遊戲畫面。

# 賽事流程回饋

2026-10-21：使用者要求進入下一階段，範圍為完成比賽、結果呈現與下一場的引導。

房主與手機使用同一個 `RaceResults` 元件，依權威 rank 排序，不重新計算名次。結算顯示賽道、本場首位有效完賽者、自己的名次／時間／距離冠軍秒數，並標記自己的排名列。DNF 不產生完賽時間或時間差；全員 DNF 顯示無人完賽。手機收到 finished 房間狀態但尚未收到最終快照時顯示同步中，避免把即時排名當作成績。

個人已完賽、整場仍在 racing 時，顯示自己的成績及剩餘等待秒數；仍由伺服器決定其他玩家完賽與 30 秒截止。結算後 Host 可原房間／原賽道直接重賽，或返回 Lobby。禁用原因沿用既有條件：有人重連、沒有已連線真人、或不足兩位已連線參賽者；畫面直接說明原因。手機等待房主操作，下一場隨權威狀態自動進入倒數。

結算面板可在短螢幕內捲動，長暱稱可換行；不新增進度存檔、獎勵、網路訊息、路由或依賴。`core/results/raceResults.ts` 僅整理呈現資料，不改伺服器比賽規則。協定維持 23。

## 瀏覽器驗證中修正的流程問題

- 參賽房主原本在結算後仍顯示底部鍵盤說明／觸控切換與道具欄，會遮住結算按鈕。現在本人完賽或整場結束後收起控制面板，輸入 hook 仍先依禁用狀態清理；保留操作模式選擇供下一場使用。
- 結算面板層級提高，手機結果使用接近不透明的背景，避免音效／畫質浮層蓋住名次。手機可在面板內捲到最後一名。
- 手機收到權威比賽階段變更時清除上一階段的暫時操作錯誤，避免過期道具提示殘留在結果頁。
- 完整三圈實際約需兩分多鐘，既有 90 秒瀏覽器駕駛上限不足。測試改為等待實際整場 finished（保留上限），未縮短圈數、跳過物理或放寬名次與背包重置驗證。

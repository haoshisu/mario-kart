# 其餘台灣地圖的世界層次優化

2026-10-18，使用者要求將台南的世界優化延伸到其他地圖。本輪範圍為台北、九份、高雄、阿里山與台中；台南保留已完成版本，其他七張非台灣主題圖不在這次範圍。這些都是原創意象場景，不是實際城市的測繪重建。

## 各地的空間語彙

- 台北：西側較低的住宅樓群與東側高樓群區分天際線；省電保留全部背景樓房及街區地坪，僅簡化屋頂壓頂、退縮塔樓細節。河道、橋與環狀盆地山稜持續構成世界邊界。
- 九份：山坡街屋由獨立小屋擴成緊密排列的聚落，屋頂、嵌坡地基與階梯巷道連續。省電保留全部背景房屋，窗洞以平面實作；遠處以連續山稜取代獨立山錐。新增彎曲海岸陸地銜接賽道聚落與山坡，移除舊的矩形陸地／水面分塊。
- 高雄：港區西側採低矮倉屋及灰綠斜頂，東側保持較高都會樓群；建築鋪面接到港區街道。省電保留全部建築，窗帶改用平面，並保留碼頭、吊車與貨輪。低山改成連續地平線。低處沿岸道路連成碼頭地坪，高架橋段保留水面；移除舊矩形內海貼片，由同一海面延續到地平線。
- 台中：增加填滿街廓的樓群、連續裙樓與側立面玻璃窗帶；西側住宅較低、東側較高，低樓帶屋頂綠化。保留貫穿城區的綠帶，外圍改用連續丘陵；縮減小型裝飾與不可見細節，把預算留給城市輪廓。
- 阿里山：新增連續山地網格與大片分層針葉林，從較暖的前景林地過渡到深色山林與三層遠山，取代原本孤立山丘。道路周圍的地形保持下凹，接續既有路肩切坡、近景神木、茶田及雲海。樹木位置與高度作確定性變化，並依地形三角形插值讓樹根貼地；山地與樹根使用相同網格高度，所有主路與支路均檢查淨空。新增完整世界俯瞰，遠裁切調為 2400 m。

## 邊界與實作

不修改賽道中心線、高程、碰撞、道具、CPU、網路資料或賽事規則；協定仍為 22。背景街道、庭院及山林均不代表新增可駛入區域。沒有新增依賴、第三方素材或 Blender 模型，近景保留既有原創 GLB。

延用各圖布局及合併幾何模組。新增 `worldRidgeGeometry.ts` 產生九份、高雄、台中及阿里山的連續遠山；`alishanWorldGeometry.ts` 與 `AlishanWorld.tsx` 管理阿里山山林及資源釋放。世界背景不增加陰影 pass。原先刪除半數或三分之二城市建築的省電策略已由保留輪廓、簡化細節取代。

既有各圖幾何預算不放寬。阿里山新增世界預算為標準 42,000／省電 24,000 個三角面；完整四車省電畫面仍要求低於 200,000。新增射線測試確認阿里山背景不遮住主路或支路。

## 畫面檢視後的收尾（2026-10-19）

九份新增 40 棟低地街屋，合計 152 棟背景房屋，填入既有道路及地標之間、實際海岸陸地範圍內；山坡屋舍仍依原山坡頂點定位。遠山往後退並將兩端收低，避免遮住聚落。阿里山的林木改為不規則排列，以地形三角形插值定位樹根；移除樹冠遮住及埋入地底的樹幹端面後，標準／省電世界分別為 32,774／18,188 面。

台中首次整圈取樣最高 203,391 面，超出 200,000 預算；省電近景細節距離由 48 m 調為 40 m，稍遠建築仍以完整輪廓呈現，標準畫質不變。阿里山首次整圈取樣最高 203,382 面，因此進行上述不可見端面優化，並將完整一圈的面數上限加入瀏覽器測試。兩者均未放寬預算或刪除背景街廓／森林。

完整 `npm run check -- -- --maxWorkers=2` 已通過 66 檔／574 項；最後的海岸、林木與效能修正另通過相關單元測試、正式建置、lint 及 `git diff --check`。台中最終整圈重測通過六個路段，取樣最高 199,661 面。阿里山最終整圈通過八個路段，取樣最高 198,250 面。最後一輪五項瀏覽器案例全數通過，包含這兩張圖的主路完整一圈，以及九份、阿里山、台中的全景、四車省電、駕駛與俯瞰；台北與高雄先前的對應案例亦通過。

最終四車省電起點取樣：台北 196,981、九份 199,185、高雄 155,510、阿里山 191,262、台中 195,398 個三角面。全部低於 200,000。這是桌面 Brave 樣本，只有台中與阿里山在本輪另驗證完整一圈峰值，不代表其餘三圖的整圈最壞情況或手機真機長時間效能。已檢視 `doc/images/taiwan-worlds/` 的最終全景與駕駛畫面。未部署。

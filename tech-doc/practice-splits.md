# 練習逐圈對照（2026-10-22）

依使用者「開始下一階段」，延續練習紀錄與巡遊，加入比賽途中的逐圈挑戰回饋。

- 每圈開始顯示最佳場次的該圈目標；完成一圈後顯示與該場次同圈過線時的累計時間差，不推算未完成路段的領先秒數。
- 結算列出三圈的本圈差與累計差，使用快／慢／持平文字和輔助顏色。過線提示以 polite 狀態播報，每幀計時不播報。
- 比較基準是本場開始時載入的最佳三圈場次，保留到結算；總時間破紀錄後也不改成本場自己。下一場重賽再採用新紀錄。其他分頁中途改變紀錄時，本場逐圈基準維持原值，但寫回總紀錄前仍讀取最新值，避免較慢結果覆蓋新紀錄。
- 紀錄加上可選 `bestRunLaps`（同一場三圈原始秒數），只在首次、總時間刷新或舊紀錄缺少逐圈資料而追平總時間時寫入。較慢但刷新單圈的場次不取代三圈基準；已有逐圈資料的平手也保留原場次。
- 原有儲存 key 與規則版本不變，舊紀錄及巡遊進度保留。缺少或損壞的逐圈資料不影響有效總時間；顯示建立對照的方式。比較採百分之一秒，累計時間先相加再四捨五入。
- 僅單人練習使用，不更動操控、賽道、多人計時、網路封包或協定 23。本輪不含幽靈車、全路線分段預估及全球排行。

## 驗證範圍

純規則驗證單圈／累計差、前快後慢、持平精度、不完整或無效資料、同場次保存、舊格式升級、較慢單圈刷新不換基準、跨分頁更新及重賽基準切換。瀏覽器使用既有診斷檢查點測試落後轉領先、結算固定基準、重賽／重新整理與舊紀錄升級，並檢視桌面與窄螢幕。診斷與種子成績不代表真人圈速或路線平衡。

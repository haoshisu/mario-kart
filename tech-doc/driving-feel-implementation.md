# 駕駛手感與台北節奏實作｜2026-10-08

使用者以「好，幫我修改」核准 [駕駛提案](driving-feel-review.md) 後實作。本輪集中在駕駛、回饋及台北的道路；沿用已核准原創 Kestrel／Aster 與台灣環境資產。其他十圖的道路拓撲不變，共享操控修正適用全部十一圖。

## 交付規則

- 漂移進入時鎖定左右方向。同向操作收內弧，反打放外弧，放開方向鍵仍沿同側弧線滑行；放開漂移鍵恢復普通轉向並釋放已充能的 Turbo。
- 只有同向有效轉向才累積充能。直行按住、空中、倒車與煞車不會刷漂移增益；反打保留已有充能，停止增加。原有三級閾值／火花沿用。17 m/s 的中間弧線半徑約 37 m，為長彎留下控制空間；此數值是共享核心的水平量測，實際坡度／碰撞／路面會影響軌跡。
- 普通最高速仍 17 m/s，第三級 Turbo 仍 23 m/s。增益結束時以每秒 4 的指數衰減回落，保留實際動量；不恢復碰撞損失，煞車仍能減速。修正權威／練習的側滑方向基底差異。
- 台北的跳台保留安全地面線。起跳前 0.14 秒的短按可緩衝，起跳後 0.22 秒內的新按鍵可做特技。提前一直按住或按得太晚，不側翻也不給特技獎勵，但能正常飛行及落地；成功時保留既有二級落地 Turbo。其他圖仍自動特技。空中狀態仍由共享特技核心決定，沒有新增網路姿態權限。
- Web Audio 程序合成原創引擎、風、滑胎、分級充能、放開增益與交會警示音。啟用音效按鈕取得使用者手勢；練習、房主本人及手機各跟隨自己的車。靜音／切到檢視／隱藏頁面停止駕駛混音，卸載停止來源、RAF、監聽與 AudioContext。沒有外部聲音素材或新依賴。
- 練習進入 RACING 時收起選圖面板，透過「選圖與賽事」重新開啟；保留圈數、速度、漂移、操作與音量。手機音效面板避開方向／漂移／煞車觸控區。
- 台北 CPU 透過既有意圖管線在彎中漂移：先收內弧取得第一級、再釋放；Turbo 期間不重複進入漂移，超出可用漂移半徑的急彎回到普通轉向。碰撞、道具、CP 與實際 Rapier 移動仍照正常規則，沒有改位置或保送充能。其他圖 CPU 策略維持原有版本。

## 台北道路

城門起跑 → 騎樓連彎 → 捷運選線 → 塔基爬升 → 屋頂高速 → 街谷大跳 → 夜市蛇行 → 河岸衝線。共八段，最大高差 30 m；騎樓轉到屋頂形成主要環境轉換，街谷大跳為保留的演出點。

主路約 **1,081.7 m**，原版約 1,129 m；寬度 6.8–8.4 m，約 **61%** 樣本寬於 8.3 m，原版約 93%。寬窄以平滑窗口變化；起跳、落地、回復與衝線保留 8.4 m。這些是路徑／樣本量測，不是實際圈速，也不能單靠長度證明更好玩。

三圈與 CP 規則保留。核心、道路與障礙行為變更使網路協定升為 **18**；前後端必須同步更新。

## 2026-10-21 第一輪操控修正：煞車優先

修正共享 Arcade Core 在處理煞車後，仍加入 Turbo、道具加速及路面推力的問題。三級 Turbo 與道具同時生效時，原本合計 23.5 m/s² 的推力甚至超過全煞車的 18 m/s²，導致煞車期間仍可能加速。

現在任何非零煞車輸入均優先於額外前進推力；倒退中的車輛也不接受前進加速增益。增益時間照常消耗，放開煞車且恢復非負速度後，尚未到期的增益可繼續生效。一般阻力與物理碰撞仍保留。練習與伺服器共用此修正，真人與 CPU 適用相同規則；道具掉落、碰撞強度與漂移充能門檻維持既有設定。

這是既有煞車／倒車優先規則的修正，未變更封包或快照欄位，協定維持 22。自動回歸涵蓋部分煞車、全煞車、疊加增益、停止後倒退與恢復前進；瀏覽器案例使用實際鍵盤輸入驗證起跑 Turbo 期間可煞停倒退。真人競賽平衡與手機實機手感仍需試玩。

驗證：`npm run check` 通過 66 檔／578 項測試，`npm run build` 通過。Production Brave 通過起跑 Turbo 期間煞停倒退，以及模擬手機橫直向介面／漂移蓄力釋放兩項測試，未出現頁面錯誤。未部署。

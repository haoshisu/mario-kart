# 台南：府城世界重製

2026-10-18 使用者指出地圖只有沿路擺設主題物件，核准先把台南改成完整城區，再評估擴展其他地圖。這輪替換台南舊的棋盤背景、散置街景、大草地及三角山，不將同樣修改套到台中。

## 空間設計

- 482 棟街屋以相連屋頂形成城市街廓；巷道從街廓中穿過，街屋高度、赭紅瓦頂、騎樓柱、窗框與布棚使用統一暖色材質。
- 連續城市地基配合既有道路高程，取代孤立道路兩側的空地；近道路地基採保守下限，避免掩住可行駛路面。
- 運河沿城內橫向穿過，切開地基，具有下凹水面、兩岸擋土、沿岸步道與船屋；原道路穿過河道的兩處增加石造橋側結構。
- 廟埕包含鋪面前庭、兩側殿廊與三層主殿，從街巷開闊成有圍合的廣場。
- 城門跨過既有道路，北側高地路段連接厚城牆，遠處不再使用重複山錐。沿海樹帶與水面延續世界邊界。
- 路面改成暖色石磚，護欄／路緣配色改成石牆；跨街燈籠與城市光照共用府城色調。

本輪重建視覺空間與道路周圍的世界；賽道中心線、高程、碰撞及賽事規則維持原版本，因此網路協定維持 22。新景物為裝飾，沒有新增可自由駛入的巷道、廟埕或水域。

## 實作與預算

`tainanWorld.ts` 負責世界布局、地基高度與淨空；`tainanWorldGeometry.ts` 合併城市幾何，`TainanWorld.tsx` 管理材質及資源釋放。保留原有建築工具給台中使用，台南不再渲染原先沿路排列的 GLB 街屋。

標準／省電保留完整街廓與水域。省電減少窗框、布棚及樹木細分，不刪掉半座城市。世界幾何上限標準 75,000／省電 45,000；完整四車省電場景仍需低於 200,000 面。背景海面先於世界繪製且不寫入深度，避免遠距大型水面遮住城區。

正式建置通過。實際瀏覽器的四車省電場景及主路完整一圈兩項測試通過，六個路段均留存截圖；四車畫面 177,044 個三角面，全圈取樣最高 194,532，低於 200,000 預算。世界本身標準 66,848／省電 33,424 個三角面。測試環境顯示約 60 FPS，這不代表所有裝置的效能保證。

`npm run check -- -- --maxWorkers=2` 的 lint、型別檢查通過；單元測試 572 項通過，台南 seed 42 電腦車三圈測試在同時執行瀏覽器驗證時超過 25 秒時限（25.384 秒）。停止並行瀏覽器負載後，以原有時限單獨重跑該案例通過（整次執行 18.07 秒），沒有放寬斷言或時限。`npm run build` 與 `git diff --check` 通過。未部署。


## 街區辨識與建築優化（2026-10-18）

依使用者「繼續優化」，本輪保留連續世界與路線，將同質街屋分成三種空間語彙：南側商街採紅磚、深色騎樓與綠白布棚；運河兩岸採低矮倉屋、灰綠橫向屋頂與寬門；北側住宅採淺色牆、露台與瓦頂混合。近路側牆補上窗洞及水平腰帶，讓轉彎視角也有立面。13 個有樹蔭及矮座牆的內嵌庭院取代部分房屋，留下 482 棟相連街屋。

建築細節抽至 `tainanArchitectureGeometry.ts`。省電保留全部街區、庭院和三種建築輪廓，遠處簡化窗飾與女兒牆，移除不可見底面。世界幾何標準 65,026／省電 37,238 個三角面；四車完整場景仍以實際瀏覽器 200,000 預算檢查。庭院為視覺景物，未新增可駛入範圍。沒有修改其他城市、賽道物理或協定。

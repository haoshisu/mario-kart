# 畫質偏好保存（2026-10-23）

依使用者「開始下一階段」，延續 Phase 6 跨裝置品質，修正重新進入遊戲即失去畫質選擇的問題。

- 標準／省電選擇存於本機 `kart-lab:render-quality:v1`，同一瀏覽器重新整理、返回練習或建房頁都會沿用；其他裝置不會同步。
- 在讀取偏好前不建立 Canvas 與場景子樹，避免已選省電的裝置先載入標準車手 GLB，再換成省電。SSR 與 hydration 使用一致的載入占位。
- 沒有有效偏好時沿用既有預設：主畫面標準，手機玩家場景省電。使用者已保存的明確選擇優先。
- 只接受 standard／low；損壞資料回到該場景預設。localStorage 讀寫失敗仍立即套用本次選擇，並顯示「無法儲存畫質，僅本次有效」。
- 不監聽其他分頁的畫質更改，避免玩家比賽中突然切換模型；下次載入才讀取新選擇。沒有自動依 FPS 調整畫質。
- 沿用現有省電渲染、WebGL 恢復與錯誤畫面。儲存模組在 `game/rendering/renderPreference.ts`；不新增依賴、網路欄位或玩法變更，協定維持 23。

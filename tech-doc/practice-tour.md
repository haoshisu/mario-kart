# 賽道巡遊挑戰（2026-10-22）

依使用者「開始下一階段」，延續本機練習紀錄，加入選圖時的長期完成目標。

- 台灣巡遊包含台北、九份、高雄、阿里山、台南、台中六站；全圖巡遊包含全部十三站。
- 每站完成合法三圈且成功保存最佳紀錄，便計為完成；既有同規則版本紀錄直接計入，不重設玩家進度。損壞或舊版紀錄不計入。
- 選圖卡顯示待挑戰／已完成及最佳總時間，選中賽道另顯示最快單圈。全部賽道保持自由選擇，沒有解鎖限制或性能獎勵。
- 下一站優先推薦尚未完成的台灣賽道，再推薦其餘賽道；有其他未完成站時避開目前選中站。完成六站／十三站時顯示達成訊息，全圖完成後改為提示挑戰個人紀錄。
- 沿用本機紀錄儲存，不另存完成旗標。選圖面板開啟時讀取，成功保存或其他分頁更動／清除紀錄時更新；每幀不讀取 localStorage。
- 儲存受阻時明示無法讀取，仍可自由選圖。紀錄僅此瀏覽器保留，清除資料或切換規則版本後對應進度會改變。
- 僅單人練習顯示巡遊。多人／CPU 道具賽維持原有選圖與結算，協定維持 23。本輪不含盃賽積分、全球排行榜、幽靈車或跨裝置同步。

純巡遊規則在 `core/race/practiceTour.ts`，集合快照／儲存更新在 `runtime/practiceTourStore.ts` 與 `usePracticeTour.ts`，畫面在 `components/PracticeTrackPicker.tsx`。

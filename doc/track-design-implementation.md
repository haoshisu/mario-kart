# 七圖 Level Design 改善對照

依據 [Kart Racing Track Design Guidelines](kart-racing-track-design-guidelines.md)。

本輪從目前七圖已有的六／七區主題樂園繼續修改，保留原創路線、上下坡、可選側線大跳、三圈、三個 Checkpoint、道具與共享權威物理。不是重新套用同一條路線。過往提案與實作記錄保留於 `tech-doc`。

## 寬度、選線與失敗成本

- 各圖主路在獨立技術路段由 8.4 m 平滑收至約 7 m，再展開。起跑、道具箱、加速帶、動態車輛與大跳起落範圍維持原寬，避免為了收窄破壞可行駛空間。
- 花谷捷徑中央從 6 m 收至 4.8 m；其他圖從 5.8 m 收至 4.6 m。出入口保持原寬並平滑合流。
- 主路主題地面只佔左半幅；白邊標示分界，右半幅可用一般操控通過。捷徑中央則要直接處理該圖的主題地面，需要修正方向、提前漂移回正或運用 Turbo／道具 Boost。
- 捷徑節省的路程維持既有差異；碰撞護欄、失去入彎速度及地面阻力是失敗成本，不新增跳點或跳過 Checkpoint。選擇主路可避開捷徑全幅主題地面。
- 可見道路、路緣、護欄、路面吸附與 Checkpoint 寬度共用資料。上下層仍依高度區分，不把高架與地面接成同一條道路。

## 導引、景觀節奏與速度回饋

捷徑合流採用同主題路面色與材質深度偏移，減少重疊道路的交錯閃爍；中央主題地面與洞穴入口仍提供選線辨識。

主題地面使用不同紋樣：側風／輸送帶箭紋、濕甲板波紋、薄冰亮紋、盤根折線、流沙／火山灰顆粒。主路前有玩法與安全線預告，捷徑入口前有窄路預告。輸送帶紋樣沿行車方向移動，不以客戶端動畫決定車速。

沿用既有高架大跳、路線上拱廊、洞穴穿越、移動障礙、三層環境與主要地標，沒有增加大量無用途模型。其他六圖改為高速區較密的近路標記、較稀的中景；技術區降低近路標記密度，集中中景，產生留白。花谷沿用原本分區密度。

沿用目前已共用的速度 FOV、邊緣流線、漂移煙霧／火花、車身傾斜、特技側翻與落地 Turbo。不新增持續鏡頭抖動。

## 規則與驗證界線

權威伺服器與單人練習共用主題操控規則，起跳／離地、道路外、倒數、結束與受控鎖定時不套用地面效果。協定升至 **16**；部署時前後端須同步。

自動驗證涵蓋七圖主路／捷徑地面效果、安全線、離地排除、輸送帶方向、Boost 對抗流沙、寬度平滑與網格／物理一致性，以及既有合法完圈、坡道、大跳與動態障礙回歸。`npm run check` 通過 46 檔／323 項，production build 通過。Brave production 七圖主題地面與七條捷徑的 14 項駕駛案例全數合法完圈；手機尺寸選圖、手機加入與 WebGL 的 2 項案例通過。合流材質調整後工坊／港都再驗 2 項通過。已逐張檢視七圖主題路面及分流、合流、手機截圖。先前一次手機補驗因前一批測試自動關閉臨時伺服器而連線被拒；重新啟動隔離環境後兩項均通過。

5～10 秒事件目標屬實際玩家速度與路線選擇的設計目標，沒有用固定間隔塞障礙。六／七區入口與中段預告、坡頂、跳台、加速選線、洞穴、地面變化及合流共同提供事件節奏；真實新手／高手的事件間隔和捷徑時間收益仍需要試玩平衡。手機真機、四人長時間效能與公開部署不是本輪本機測試能代替的驗收。
